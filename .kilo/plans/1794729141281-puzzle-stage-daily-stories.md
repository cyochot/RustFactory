# パズルステージ物語の日常コメディ化

## 目的

パズルステージの物語を、くるみちゃんとフェリス達が登場する、1話完結のゆるい日常コメディにする。各話はステージ状況に軽く関連づけてもよいが、Rust概念やパズルの仕組み・解法は会話で説明しない。

## 対象と制約

- `src/data/storyChapter1.ts`〜`storyChapter20.ts` のうち、`src/data/stages.ts` で `stageKind` が `puzzle` または `challenge` のステージに対応する物語エントリー（約180件）。
- `basic` ステージの物語は変更しない。
- `stageId`、ステージ定義、攻略情報、物語の型や表示動作は変更しない。対象エントリーの `requestTitle`、`intro`、`outro` の文面を更新する。`client` と話者ID・感情値は既存の有効値を維持する。
- 各話は前後の章やステージを知らなくても成立させる。`challenge` も章末の大筋・最終回として扱わず、単独で楽しめる少し大きめの日常回にする。
- キャラクターの口調を保ち、題材・登場人物・オチに変化をつけて定型文の反復を避ける。

## 作業手順

1. `stages.ts` のUUIDと `stageKind` を章別ストーリーと照合し、対象エントリーを特定する。
2. 20個の章別ファイルで対象エントリーのタイトルと会話を、軽い日常コメディに書き換える。通常ステージの物語はそのまま残す。
3. 全UUIDの対応と対象範囲を確認し、会話にRust用語・攻略手順・章をまたぐ筋書きが残っていないかレビューする。

## 検証

- `npm run verify:stages`
- `npm run lint`
- `npm run build`
- 差分を確認し、`basic` のストーリー、ステージデータ、UUIDが不変であることを確認する。
