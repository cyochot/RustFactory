# ステージ選択カードの表示整理

## 目的と確定方針

- ステージ選択画面の既存の解放順を維持する。
- ステージカードの `#001` 形式の通し番号と「第N章 章タイトル」を削除する。
- カードには教材上の `*-*` 形式の `displayId` を残し、種別・トピック・タイトル・目標・クリア/ロック状態も維持する。
- 章フィルター、クリア状況・種別フィルター、現在のステージへのジャンプは変更しない。
- ステージデータ、ID、進捗保存、ロック条件には変更を加えない。

## 実装タスク

1. `src/components/StageAtlasModal.tsx` のカードメタデータ行から `st.index` による `#*` 表示と `st.chapter` / `st.chapterTitle` 表示、およびそれらに付随する区切り記号を削除する。
2. `st.displayId` を残し、カードの他の情報・動作を維持する。
3. `chapterStages` の `index` 昇順ソートと後続フィルター処理を変更せず、章・状態・種別で絞り込んでも該当ステージの相対的な解放順が維持されることを確認する。

## 影響範囲と検証

- 変更対象は `src/components/StageAtlasModal.tsx` のカード表示のみ。
- `npm run lint` と `npm run verify:stages` を実行する。
- 差分を確認し、`#*` とカード上の章ラベルだけがなくなり、`*-*`、他のカード情報、章フィルター、解放順が維持されていることを確認する。
