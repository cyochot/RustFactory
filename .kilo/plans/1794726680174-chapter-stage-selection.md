# ステージ一覧を章選択式に変更

## 目的
「ステージ一覧」を章フィルタ付きのフラット一覧から、章を選択してからその章のステージを選ぶ2段階画面に変更する。

## 決定事項
- 章選択画面と章内ステージ一覧画面を同じモーダル内で切り替える。
- 章選択画面では全章を選択可能にする。章カードには章番号と既存の `chapterTitle` を表示し、章内ステージ数・クリア数も確認できるようにする。
- 章内一覧には選択した章のステージを `StageDefinition.index` 順で表示する。
- 現在のクリア状況フィルタと種別フィルタは章内一覧に残す。章を移る際は両方を「すべて」に戻し、章間で絞り込みが残って空一覧になる混乱を避ける。
- ステージカードの情報と解放条件、フリー解放切替を維持する。未解放ステージは従来どおりロック表示し、全章を見られることと開始可否を分離する。
- ステージカードには既存の教材表示IDのみを維持し、通し番号やUUIDは追加しない。
- 「現在のステージへ」は現在ステージの章を開き、状況・種別フィルタを解除して現在ステージへスクロールする。
- 章内一覧から章選択画面へ戻れる導線を用意する。閉じる操作、ステージ選択コールバック、フリー解放設定の挙動は維持する。

## 実装タスク
1. `src/components/StageAtlasModal.tsx` の章選択状態を「章一覧 / 選択中の章」に置き換え、章一覧画面を追加する。章データは渡された `stages` から章番号順に集約し、章タイトルと件数・クリア数を導出する。
2. 既存のフラット一覧を章内一覧として使い、選択章のステージだけを表示する。章選択へ戻るボタンを置き、別章へ移動したら状況・種別フィルタを初期化する。
3. 現在ステージへのジャンプ操作は対象章を選択し、フィルタを解除したうえで既存の `pendingJumpId` とスクロール参照を使うよう変更する。章ビューからステージ一覧への切り替え後にもスクロールが実行されることを確認する。
4. 既存の空状態、絞り込み解除、レスポンシブなモーダル内スクロールを維持し、章選択画面でも小さい画面で操作可能にする。

## 対象範囲外
- 進捗データ、章・ステージ定義、保存形式、ステージ解放ルールの変更。
- 章ごとのロックや章単位の解放条件導入。
- ステージ選択後のゲーム画面やモーダル起動元の変更。

## 検証
- `npm run lint`
- `npm run verify:stages`
- `npm run build`
- 手動確認: 章選択から各章へ移動、章内順序、章移動時のフィルタ初期化、フィルタで0件時の復帰、ロック中ステージの表示と選択不可、フリー解放切替、現在ステージへのジャンプ（フィルタ適用中を含む）、狭い画面での操作。
